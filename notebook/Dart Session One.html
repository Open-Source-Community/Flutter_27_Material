أنواع الداتا بالتفصيل

الأرقام: int و double و num

int age = 20;         // أرقام صحيحة
double price = 9.99;  // أرقام بكسور
num n = 5;            // num بتشيل int أو double
n = 2.5;              // ✅ ينفع لأن num هي الأب بتاعهم
// int x = 5.5;       // ❌ Error: 5.5 مش int

num هي الـ Parent لـ int و double، وده أول مثال عملي على الـ Inheritance. لما نقول num معناها "أي رقم". ولما نحدد int بنضيّق وبنقول "صحيح بس".

الـ String

String a = 'single quote';
String b = "double quote";
String c = '''سطر أول
سطر تاني
سطر تالت''';   // triple quotes للنص على أكتر من سطر
  • الـ S كابيتال (String مش string).
  • الـ Single والـ Double شغالين نفس الشغل، والـ Triple لو النص متعدد الأسطر.
  • لو النص جواه علامة اقتباس، استخدم النوع التاني: "It's Dart".
  • الـ String ليها ميثودز كتير زي length و toUpperCase() (هنشوفها في قسم التحويل).

الـ bool والـ Collections

bool isOk = true;

List<int> list = [1, 2, 3, 3];   // مرتبة، وبتقبل التكرار، وبتبدأ من index 0
Set<int>  set  = {1, 2, 3, 3};   // مفيش تكرار: هتتحول لـ {1, 2, 3}
Map<String, int> map = {'ali': 20, 'mona': 22};  // key و value

الأقواس بتفرّق:

  • [ ] → List
  • { } بقيم لوحدها → Set
  • { key: value } → Map

var x = {}; دي Map مش Set. لو عايز Set فاضي اكتب <int>{}.

أنواع أقل استخدامًا: Runes و Symbol و Null

  • Runes: بتمثّل الـ Unicode بتاع الحروف والـ Emoji. الكمبيوتر بيخزّن كل حرف كرقم (زي الـ ASCII: A = 65). والـ Unicode أوسع وفيه الـ Emoji كمان.
Runes r = Runes('\u{1F600}');      // الكود بتاع الـ Emoji
print(String.fromCharCodes(r));    // بيرجّعه لشكله
  • Symbol: بتتكتب #name وده نادر الاستخدام.
  • Null: النوع بتاع القيمة null (يعني "مفيش قيمة"). ده أساس Null Safety.

قايمة الأنواع التسعة: num (و int و double) · String · bool · List · Set · Map · Runes · Symbol · Null.

الـ String Interpolation (بدل الـ +)

  • $x → قيمة متغير.

تعريف المتغير: النوع الصريح مقابل var

الطريقة الأولى: نكتب النوع بنفسنا

int age = 20;
String name = 'Ali';

كده إنت عملت Restriction: مش هيقبل غير النوع ده. int x = 5.5; ← Error.

الطريقة التانية: var

var x = 5;   // Dart فهم إنها int
x = 8;       // ✅ قيمة جديدة من نفس النوع
// x = 5.5;  // ❌ Error: النوع اتحدد خلاص

القاعدة اللي لازم تتحفظ: مع var النوع بيتحدد من أول قيمة وبعد كده ما ينفعش يتغير، لكن القيمة تتغير عادي.

الحالة الغريبة: var من غير قيمة

var y;                  // مفيش قيمة ومفيش نوع
print(y);               // null
print(y.runtimeType);   // Null
y = 'Dart';             // ✅ ينفع
y = 10;                 // ✅ برضه ينفع

var y; من غير قيمة بتبقى في الحقيقة dynamic، فبتقبل أي نوع بعد كده. دي نقطة الطلبة بتتلخبط فيها، فقولهم: "لو عايز النوع يتثبت، حط قيمة أول ما تعرّف".

runtimeType بيجيبلك النوع الفعلي وقت التشغيل. أداة حلوة للتجريب.

الثوابت: const مقابل final

الاتنين معناهم: اتحط له قيمة مرة واحدة وخلاص. الفرق في إمتى القيمة بتتحدد:

  • const → Compile Time. القيمة لازم تكون معروفة وإنت بتكتب الكود، يعني قيمة صريحة. ممنوع عملية حسابية بمتغيرات عادية.
  • final → Run Time. القيمة بتتحسب وقت التشغيل، فينفع تاخد ناتج عملية حسابية.
int a = 1;
int b = 2;

const x = 9;            // ✅ قيمة صريحة
// const z = a + b;     // ❌ a و b مش ثوابت
final y = a + b;        // ✅ بتتحسب وقت التشغيل
// y = 7;               // ❌ اتحطت مرة وخلاص

تشبيه سهل: const زي ما تكتب رقم الأوضة في الورقة قبل ما تروح. final زي ما تستنى لحد ما توصل وتشوف رقم الأوضة وبعدين تحطه ومتغيّرهوش.

الفرق مع الـ List (النقطة اللي هتوضّح كل حاجة)

const c = [1, 2, 3];
// c.add(4);     // ❌ Exception وقت التشغيل
// c[0] = 7;     // ❌ Exception
// الـ List بقت Read-Only بالكامل

final f = [4, 5, 6];
f.add(7);        // ✅ ينفع
f[0] = 10;       // ✅ ينفع
// f = [8, 9];   // ❌ Compile Error، المتغير نفسه ثابت

الخلاصة: final بتثبّت المتغير (ماينفعش يشاور على حاجة تانية). const بتثبّت المتغير والمحتوى كمان.

المتغيرات اللي بتغير النوع: dynamic و Object

دلوقتي المتغير ممكن يغير القيمة والنوع مع بعض:

dynamic x = 1;
x = 'Dart';   // ✅
x = true;     // ✅
x = 2.5;      // ✅

Object y = 1;
y = 'Dart';   // ✅ نفس الفكرة

الاتنين بيعملوا نفس الشغل، والفرق:

  • dynamic مجرد كلمة بتقول لـ Dart "سيبه يتغير". بسيطة ومش هتجيب مشاكل. ننصح بيها للمبتدئين.
  • Object دي الـ Parent Class لكل الـ Classes في Dart، وراها مفهوم الـ Inheritance. استخدمها لما تفهم الـ OOP.

⚠️ الفخ: استدعاء Method على متغير بيتغير نوعه

dynamic x = 'Dart';
print(x.toUpperCase()); // شغال لأن x دلوقتي String

x = 5;
print(x.toUpperCase()); // 💥 Exception وقت التشغيل
// Class 'int' has no instance method 'toUpperCase'

مع dynamic الـ Compiler مش بيعترض، والمشكلة بتظهر لما اليوزر يشغّل (Run Time).

مع Object الوضع أصعب: الـ Compiler بيعترض من الأول:

Object y = 'Dart';
// print(y.toUpperCase()); // ❌ Compile Error
// ليه؟ لأن Dart بتدوّر على toUpperCase جوه كلاس Object، مش جوه String

الـ y شايلة String فعلًا، بس الـ Variable متعرّف كـ Object، فـ Dart بتتعامل معاه كـ Object.

الحل: is (بتفحص وبتعمل Cast في نفس الوقت)

if (y is String) {
  print(y.toUpperCase()); // ✅ Smart Cast تلقائي
}
  • is بتسأل: هو من النوع ده؟ ولو آه، بتحوّله تلقائيًا جوه الـ if (اسمها Smart Cast).
  • is! عكسها.
  • as بتعمل Cast يدوي: String s = y as String;
  • ⚠️ لو حاولت تعمل as String على متغير جواه int هتاخد Type Cast Error.

قاعدة ذهبية: مع أي dynamic أو Object، افحص النوع بـ is قبل ما تنادي أي Method.

Cast بين إيه وإيه؟

الـ Cast بيبقى بين Parent و Child (من Object لـ String مثلًا). مش بين int و String، دول Children مش بيتحولوا لبعض بـ as. للتحويل بينهم هنستخدم parse و toString (القسم التالت).

الـ Operators بالتفصيل

في Dart اتنين عشر نوع Operators. اللي هو زي C++ و Java بنمشي عليه بسرعة، واللي اتفرّق بنوقف عنده.

١) الحسابية (Arithmetic)

print(7 + 2);   // 9
print(7 - 2);   // 5
print(7 * 2);   // 14
print(7 % 2);   // 1  (الباقي)
print(7 / 2);   // 3.5  ← بترجّع double دايمًا
print(7 ~/ 2);  // 3    ← قسمة صحيحة بترجّع int

ده الفرق الأهم: في Java و C++ لو قسمت int على int بتطلع int. في Dart الـ / بترجّع double دايمًا (حتى 4 / 2 = 2.0)، ولو عايز int استخدم ~/.

٢) الزيادة والنقصان (Increment / Decrement)

x++ مش بالظبط زي x + 1، لأن x++ بتغيّر x نفسها، أما x + 1 بتحسب بس ومبتغيّرش حاجة.

int x = 5;
print(x++);   // بيطبع 5 وبعدين x بقت 6   ← Postfix: يستخدم وبعدين يزوّد
print(x);     // 6
print(++x);   // بيزوّد الأول (7) وبعدين يطبع 7  ← Prefix

القاعدة: الـ ++ بعد المتغير (Postfix) = استخدم القيمة وبعدين زوّد. الـ ++ قبله (Prefix) = زوّد وبعدين استخدم.

٣) المقارنة (Comparison)

== و != و > و < و >= و <=. وناتجهم دايمًا bool (true أو false).

print(5 == 5);   // true
print(5 != 3);   // true
print(5 > 8);    // false

٤) المنطقية (Logical)

&& (And) و || (Or) و ! (Not). بتشتغل على قيم bool وبترجّع bool.

ABAnd (&&)Or (والتانية)
truetruetruetrue
truefalsefalsetrue
falsetruefalsetrue
falsefalsefalsefalse
  • الـ && لازم الاتنين true.
  • الـ || يكفي واحد true.
  • الـ ! بتعكس القيمة.

٥) الـ Bitwise (على مستوى البتّات)

الفرق بين الـ Logical والـ Bitwise: الـ Logical بياخد bool ويطلّع bool. الـ Bitwise بياخد أرقام وبيشتغل على كل Bit في الرقم الـ Binary (في Dart الرقم الصحيح بيتمثّل بـ 64 bit).

// 5 = 0101   ،   3 = 0011
print(5 & 3);   // 0001 = 1   (And: الاتنين 1)
print(5 | 3);   // 0111 = 7   (Or: واحد منهم 1)
print(5 ^ 3);   // 0110 = 6   (Xor: مختلفين)
print(~5);      // -6         (Not: بيقلب كل البتّات)

الـ Shift:

print(1 << 3);   // 8   (Shift Left: بيضرب في 2 بالأس 3)
print(16 >> 2);  // 4   (Shift Right: بيقسم على 2 بالأس 2)

القانون: x << n = x * 2^n و x >> n = x ~/ 2^n.

٦) التخصيص (Assignment)

int x = 10;
x += 5;   // x = x + 5  → 15
x -= 3;   // 12
x *= 2;   // 24
x ~/= 5;  // 4
x %= 3;   // 1

٧) الشرطي (Ternary)

int age = 20;
String s = age >= 18 ? 'Adult' : 'Minor';   // شرط ? لو true : لو false

٨) فحص النوع والـ Cast

  • x is String بترجّع true لو النوع ده، و x is! String عكسها.
  • x as String بتحوّل النوع، وبترمي Error لو مش من النوع ده.

٩) أوبريتورات الـ Null والـ Cascade

دول اللي خصّصنالهم قسم لوحدهم: ?. و ! و ?? و ??= و ... شوفهم في Null Safety.

الحل: كل نوع ليه شكلين

String  name;   // Non-Nullable: ممنوع يشيل null
String? name2;  // Nullable: مسموح يشيل null

علامة الاستفهام ? = مسموح بـ null. وده مع كل الأنواع (int? و double? و List?...).

١) الـ Non-Nullable لازم ياخد قيمة

class Test {
  String name; // ❌ Compile Error: لازم قيمة ابتدائية
}

إنت ما ادّتوش قيمة فمعناها null، وهو معرّف Non-Nullable، فالـ Compiler بيرفض.

٢) الـ Nullable: الـ Compiler ماشي وراك

String? name;
print(name.toUpperCase()); // ❌ Compile Error

أول ما المتغير يبقى ? الـ Compiler بيراقبك في كل استخدام، وبيقولك أحد حلين: ?. أو !.

Null Safety

Dart Course | مرجع أنا والفايسيز والشباب

الأوبريتور التاني: ! (Null Assertion / Force Unwrapping) — الخطر

معناه: "أنا ضامن إن القيمة مش null، كمّل".

String? name1;
print(name1!.toUpperCase()); // 💥 Exception لو name1 فعلًا null
  • لو فيه قيمة → عادي.
  • لو null → Exception وبيقف الكود.

الـ ! مش حل لمشكلة الـ null. هو بس بيقول للـ Compiler "اسكت أنا مسؤول". استخدمه بس لما تكون متأكد 100%.

ناتج ! بيكون Non-Nullable:

String newString1 = name1!.toUpperCase(); // String عادي مش String?

طب لو عندي if، ليه أحتاج !؟

سؤال ممتاز بيتسأل. الإجابة: لما تحتاج تبعت قيمة Nullable لحاجة بتطلب Non-Nullable:

void test(String s) { ... }  // محتاجة String عادي

String? name;
// test(name);   // ❌ مش هينفع
test(name!);     // ✅ حوّلتها Non-Nullable (Force Unwrapping)

معلومة زيادة: لو المتغير Local وعملت if (name != null) الـ Compiler غالبًا بيعمل Promotion لوحده وتستغنى عن ! جوه الـ if. بس الـ Instance Variables (جوه الـ Classes) مش بتتعامل كده، وده هنشوفه في الـ OOP.

?? (If Null) — قيمة بديلة

String? name;
print('Welcome ${name ?? "Guest"}'); // Welcome Guest

name = 'Dart User';
print('Welcome ${name ?? "Guest"}'); // Welcome Dart User

معناه: لو name مش null استخدمه، وإلا استخدم القيمة اللي بعد ??. ملهاش تغيير في name نفسه.

String newName = name ?? 'Guest'; // محتاج متغير جديد تخزن فيه

??= (Assign If Null) — بيعدّل المتغير نفسه

name ??= 'Guest User';
print('Hello $name'); // لو كان null بقى Guest User، ولو فيه قيمة فضل زي ما هو

الفرق: ?? بترجّع قيمة (محتاجة تخزنها). ??= بتحط القيمة في نفس المتغير.

Higher-Order Functions

Higher-Order Function = Function بتاخد Function كـ Parameter أو بترجّع Function.

النوع الأول: بتاخد Function

void calc({required int x, required int y, Function? operation}) {
  if (operation != null) {
    print(operation(x, y));
  } else {
    print('Default (addition): ${x + y}');
  }
}

Function f = (int x, int y) => x + y;
calc(x: 5, y: 8, operation: f);                          // 13
calc(x: 5, y: 8, operation: (int x, int y) => x * y);    // 40  ← الشكل الشائع
calc(x: 5, y: 8);                                        // Default
  • الـ Function الاختيارية لازم تبقى Function?.
  • ⚠️ فحص operation != null قبل الاستدعاء مهم.

النوع التاني: بترجّع Function

Function? calc1(String op) {
  switch (op) {
    case 'add':   return (int x, int y) => x + y;
    case 'times': return (int x, int y) => x * y;
    default:      return null;
  }
}

Function? fn = calc1('add');
print(fn!(3, 4));            // 7   ← ! لأن Function? ممكن تبقى null
print(calc1('times')!(3, 4)); // 12  ← الشكل المختصر

تركة للشرح: في أول مرة الـ default كان بيرجّع 0 لما العملية مش موجودة. المحاضر نبّه إن 0 قيمة صحيحة فهتخدع اليوزر (كأن العملية اتحسبت). الصح تطلع null أو رسالة. دي بتعلّم فكرة إن الـ null أحيانًا معلومة مش مشكلة.

نصيحة إضافية: Function لوحدها مش بتحدد شكل الـ Parameters. الأدق تكتب int Function(int, int) وساعتها الـ Compiler يفحص لك الأنواع. (اختياري، لو الطلبة مرتاحين.)

Extension Functions

المشكلة: عندك Function بتعمل Capital لأول حرف في كل كلمة، وعايز تكتب name.capitalize() زي ما بتكتب name.toUpperCase(). ماينفعش تعدّل في كلاس String... بس ينفع تعمل Extension.

// string_ext.dart
extension StringExtension on String {
  String capitalize() {
    if (isEmpty) return this;
    return split(' ')
        .map((w) => '${w[0].toUpperCase()}${w.substring(1).toLowerCase()}')
        .join(' ');
  }
}

الاستخدام (لازم import للملف):

import 'string_ext.dart';

void main() {
  print('fLutTeR dArT'.capitalize()); // Flutter Dart
}

شرح الأجزاء:

  • extension الكلمة المفتاحية. StringExtension اسم اختياري.
  • on String دي المهمة: بتقول الـ Extension ده هيتضاف لكلاس String.
  • جوه الـ Extension مفيش Parameter للـ String لأن this = الـ String اللي نادت الـ Function. وتقدر تشيل this وتكتب split(' ') على طول.

الـ Extension مالوش علاقة بالـ Inheritance. ده بس بيضيف Methods.

مثال تاني: Extension على Stdin (يرجع لقراءة الـ Input):

import 'dart:io';

extension InExtensions on Stdin {
  int? readInt() => int.tryParse(stdin.readLineSync()!);
}

// الاستخدام
int? n = stdin.readInt();
print('You entered: ${n ?? 'Invalid number'}');

ينفع تعمل Extension على أي Class: int و double وحتى كلاسات إنت عاملها. 💡 الفايدة العملية: مع الوقت هيبقى عندك Folder اسمه extensions بتشيله معاك في كل Project. في Flutter بتختصر كود كتير في سطر واحد.
